# 🚀 PROJECT: AI DEAL HUNTER / SALE SNIPER

You are an expert full-stack engineer, AI engineer, automation architect, security engineer and product designer.

Build a production-quality web application called:

**AI Deal Hunter — Sale Sniper**

The application continuously discovers and evaluates legitimate product deals from supported e-commerce platforms and immediately alerts the user when a deal matches their rules.

The system must be modular, scalable, secure, observable and easy to extend with additional marketplaces later.

---

# 1. CORE PRODUCT VISION

The user wants an AI agent that continuously monitors supported e-commerce marketplaces during major sale events.

Example marketplaces:

* Amazon
* Flipkart
* Meesho
* Croma
* Reliance Digital
* Vijay Sales
* Tata Cliq
* Myntra for applicable categories
* Other marketplaces through officially permitted integrations

The agent should:

1. Discover products/deals.
2. Normalize product information.
3. Track historical prices.
4. Calculate real discount percentage.
5. Detect unusual price drops.
6. Detect potentially erroneous pricing.
7. Evaluate the user's custom deal rules.
8. Rank deals by confidence/value.
9. Immediately send notifications.
10. Open the exact product URL.
11. Prevent duplicate alerts.
12. Maintain complete deal history.
13. Provide a dashboard showing detected deals and task status.
14. Support multiple user-created monitoring tasks.
15. Support AI-assisted deal analysis.
16. Prepare checkout automatically where technically permitted.
17. Require explicit user confirmation before an irreversible purchase/payment.
